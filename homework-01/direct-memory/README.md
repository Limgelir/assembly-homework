# 使用 DEBUG 直接写内存执行 Hello world

本实验使用 DEBUG 的 `e` 命令，将字符串与机器码直接写入被调试程序的内存区域，再设置指令指针并执行。程序成功输出 `Hello world!`，以返回码 0 正常结束。

## 内存安排

| 内容 | 地址范围 | 长度 |
| --- | --- | --- |
| 机器码 | `CS:0100` 至 `CS:010F` | 16 字节 |
| 字符串及结束标记 | `CS:0200` 至 `CS:020E` | 15 字节 |

代码和数据放在同一个段的不同区域，不会互相覆盖。程序通过 `MOV AX,CS`、`MOV DS,AX` 设置 `DS=CS`，因此 `DS:0200` 就是字符串地址。使用当前 CS，不依赖某次运行中特定的绝对段地址。

## 操作步骤

在 DOSBox 中运行 `debug`，不指定 EXE 文件。进入 `-` 提示符后逐步输入下面的命令。DEBUG 的数字默认是十六进制，不加 `H` 后缀。

1. 写入字符串数据：

   ```text
   e cs:0200 48 65 6c 6c 6f 20 77 6f 72 6c 64 21 0d 0a 24
   ```

   前 12 个字节是 `Hello world!` 的 ASCII 编码，`0D 0A` 是回车和换行，`24` 是 `$`，用作 DOS 09h 字符串输出功能的结束标记。

2. 写入机器码：

   ```text
   e cs:0100 8c c8 8e d8 ba 00 02 b4 09 cd 21 b8 00 4c cd 21
   ```

3. 检查内存中的数据与代码：

   ```text
   d cs:0200 020e
   u cs:0100 010f
   ```

4. 设置指令指针。先输入 `r ip`，在 DEBUG 出现冒号提示后输入 `0100`：

   ```text
   r ip
   0100
   ```

5. 查看寄存器并执行：

   ```text
   r
   g
   ```

6. 程序结束后输入 `q`，退出 DEBUG。

完整命令保存在 [MEMHELLO.TXT](MEMHELLO.TXT)。也可将它作为 DEBUG 的标准输入，在同目录的 DOSBox 命令行中执行 `debug < memhello.txt`，复现整个过程。

## 机器码与汇编指令对应关系

| 偏移 | 机器码 | 汇编指令 | 作用 |
| --- | --- | --- | --- |
| `0100` | `8C C8` | `MOV AX,CS` | 取得当前代码段地址 |
| `0102` | `8E D8` | `MOV DS,AX` | 设置数据段与代码段相同 |
| `0104` | `BA 00 02` | `MOV DX,0200` | 设置字符串偏移地址 |
| `0107` | `B4 09` | `MOV AH,09` | 选择 DOS 字符串输出功能 |
| `0109` | `CD 21` | `INT 21` | 输出字符串 |
| `010B` | `B8 00 4C` | `MOV AX,4C00` | 设置退出功能和返回码 |
| `010E` | `CD 21` | `INT 21` | 正常退出 |

`BA 00 02` 中的立即数是 `0200h`，`B8 00 4C` 中的立即数是 `4C00h`，体现了 x86 多字节数值的低字节在前存储规则。

## 运行结果

2026 年 10 月 21 日在 DOSBox 0.74 与 FreeDOS Debug 2.50 中执行上述命令，实际结果为：

```text
-g
Hello world!

Program terminated normally (0000)
-q
```

完整的内存数据、反汇编、寄存器和执行结果见 [direct-memory-debug.txt](../verification/direct-memory-debug.txt)。其中 `0724` 是该次运行的段值，复现时不必相同。

## 原理说明

- `e` 写入内存字节，不负责改变程序的执行位置；`r ip` 将执行起点设置为 `CS:0100`。
- `CS:IP` 决定下一条指令的位置；本例的 `DS:DX` 指向要输出的字符串。
- `AH=09h` 的 `INT 21h` 输出 `$` 结束的字符串；`AH=4Ch` 的 `INT 21h` 结束程序，AL 是返回码。
- 传统方式由汇编器、链接器生成 EXE，再由 DOS 加载；本方式直接把已经确定的机器码和数据写入内存。两种方式最终执行的都是机器指令。
