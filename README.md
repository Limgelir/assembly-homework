# Assembly Homework

x86 汇编语言课程作业，使用 DOSBox 0.74、MASM 5.00、LINK 3.60 和 DOS DEBUG。

| 作业 | 内容 | 提交材料 |
| --- | --- | --- |
| [作业一 Hello world](homework-01/README.md) | 传统汇编链接、DEBUG 反汇编与单步执行、直接写内存执行 | ASM 源代码、DOS EXE、实验文档和实际运行记录 |

作业按 `homework-01`、`homework-02` 等目录组织。当前包含作业一。

这些程序是 16 位 DOS 程序，需要在 DOSBox 等兼容环境中运行。仓库中的 EXE 是作业要求提交的程序成品。
